# 工具、限制与宿主行为

应用程序 SDK 文档的一部分 — 请从 [README](../../README.zh-CN.md) 开始阅读。

## 13. 工具

```bash
python3 plugin/tools/pack.py plugin/examples/music
```

把一个目录（`app.json` 清单加上它引用的文件）打包成单文件的 `music.macos-app.json` 包。在 设置 → 应用程序 中安装它，或者直接把文件拖到桌面上。

不离开页面也能做同样的事：开发者工具 ▸ 应用程序 ▸ **打包文件夹…**（或者对从文件夹载入的应用程序使用 **导出安装包**）。

`plugin/macos.d.ts` 包含整个运行时 API 的 TypeScript 类型定义 — 每个方法、节点属性以及每个事件的 detail。把它放在源码旁边，并加上 `/// <reference path="./macos.d.ts" />`（或者在 `jsconfig.json` 中列出它），就能在编辑器里得到补全和检查；普通的 JavaScript 文件同样受益。

## 14. 当前限制

SDK 目前有意不做的事情，方便你提前规划：

- 每个应用一个窗口，除非用户允许同一应用多开（§8 的 *多开*）；没有检查器窗口或偏好设置窗口。
- 应用只在其窗口存在时运行。没有后台执行，所以后台同步无法实现；提醒则用定时通知来做（`macos.notifications.schedule`，§7），由系统在应用没有运行时显示。
- `html` 节点是静态的。需要交互的自定义区域要用 `canvas`（绘制加指针事件）或 Web 运行时。
- 没有带可拖动分隔条的分栏视图；可以用 `stack`、`canvas` 指针事件和 `macos.ui.showMenu()` 自己拼一个。
- `macos.storage` 是不带查询的键值存储（每个值 4 MB，每个应用 32 MB）；大量数据请放在 `macos.files` 中。
- 浏览器保留的快捷键（`⌘T`、`⌘W`、`⌘N` 等）永远无法绑定。
- SDK 正在积极开发中，不同构建之间不保持包的兼容。

## 15. 启动时打开

设置 → 应用程序 为每个已安装的应用程序显示一个 **打开新标签页时启动** 开关。它默认关闭，并且只是用户偏好：应用程序包不能请求它，`macos` API 不能更改它，导入设置文件会把它重置为关闭。

## 16. 限制覆盖层包

“网页时间管理”的覆盖层仍然是声明式的，而不是可执行的：

```json
{
  "id": "my-limit-overlay",
  "name": "My Overlay",
  "version": "1.0.0",
  "kind": "limit-overlay",
  "actions": ["delay5", "dismiss"],
  "overlay": {
    "html": "<main>...<button data-macos-action=\"delay5\">Five more minutes</button></main>",
    "css": "..."
  }
}
```

必须有一个 `delay5` 动作和对应的 `[data-macos-action="delay5"]` 控件。限制覆盖层得不到可执行应用的运行时 API。

### 开发者工具：任务管理器与性能监视器

打开 开发者模式 ▸ 开发者工具 后，有两个面板显示各应用程序给桌面带来的开销：

- **任务管理器** 列出每个正在运行的应用程序窗口 — 状态、每秒 API 调用数、系统为应答这些调用花费的主线程时间、发给它的事件数、其原生界面的大小 — 并带有“显示”“重新载入”和“退出”；下方是系统自己的窗口。
- **性能监视器** 绘出最近一分钟的图表：帧率、最慢的一帧、长任务、JS 内存、DOM 大小，以及应用程序与系统之间的通信量，然后按占比列出各应用程序。

应用程序在自己沙盒内部做了什么，宿主是看不到的；一个在沙盒里很重的应用程序，表现为帧率低，而它自身的通信量很少。

## 17. Public Beta 0.6.2 宿主行为

- **关闭额外功能** 会挂起应用运行时，并把插件启动器从桌面、程序坞、启动台和聚焦搜索中隐藏，但不删除已保存的启动器配置。
- **使用透明代替磨砂玻璃**（设置 → 辅助功能）关闭宿主的背景采样，同时保留相同语义的半透明窗口材质。那里的显示选项 — 减弱动态效果、降低透明度、增强对比度 — 不需要开发者模式即可生效；应用程序可以在 `macos.context` / `macos.system.getInfo()` 中读到它们。
- **关闭严格安全性** 让用户可以对单个应用程序放宽限制；它并不授予对宿主 DOM 或 `chrome.*` 的访问。
- **窗口。** 把窗口拖到桌面的左边缘或右边缘，它会占据那一半；拖到顶部则铺满桌面（设置 → 桌面与窗口）；拖离后恢复原来的尺寸。半屏会遵守窗口的 `minWidth` / `maxWidth`；清单不允许在两个方向上调整大小的窗口不会被左右平铺。应用程序通过普通的 `resize` 事件得知。
- **从右到左。** 阿拉伯语是一种系统语言；使用它，或者使用 开发者 ▸ **强制从右到左布局**（文字保持原样）时，桌面会镜像：菜单栏、程序坞、窗口内容和红绿灯按钮，通知中心在左侧。窗口本身仍按屏幕坐标放置。
- **窗口记忆。** 应用程序的窗口会在用户上次离开时的位置和尺寸重新打开（缩放或平铺过的窗口：它会恢复到的那个框架）；如果桌面此后变小了，会保证窗口留在屏幕内。`window.width` / `height` 是首次启动时的尺寸。
- **字幕** 的位置由用户决定：底部、顶部，或者拖到画面上的任意位置（设置 → 辅助功能 → 字幕）。
- **开发者工具** 有自己的图标：工具开启时出现在启动台中，其窗口打开时出现在程序坞中。
- **调度中心**（⌃↑、F3 或“窗口”菜单）把所有打开的窗口并排铺开。这些窗口是活的，只是被缩小了；应用程序不会为此收到事件。
- 应用程序包只有在应用真正打开时才会加载。
- 启动台原生的横向翻页是浏览器的滚动物理加 CSS scroll snap；应用无法拦截或合成启动台的翻页行为。
