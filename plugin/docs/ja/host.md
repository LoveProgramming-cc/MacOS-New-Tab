# ツール、制限、ホストの挙動

アプリケーション SDK ドキュメントの一部です — [README](../../README.ja.md) から読み始めてください。

## 13. ツール

```bash
python3 plugin/tools/pack.py plugin/examples/music
```

ディレクトリ（`app.json` マニフェストと、それが参照するファイル）を、1 ファイルの `music.macos-app.json` パッケージにまとめます。設定 → アプリケーション からインストールするか、ファイルをそのままデスクトップにドロップしてください。

ページを離れずに同じことができます：デベロッパツール ▸ アプリケーション ▸ **フォルダをパッケージ化…**（フォルダから読み込んだアプリケーションなら **パッケージを書き出す**）。

`plugin/macos.d.ts` には、ランタイム API 全体の TypeScript 型定義が入っています — すべてのメソッド、ノードのプロパティ、すべてのイベントの detail。ソースの隣に置いて `/// <reference path="./macos.d.ts" />` を加える（または `jsconfig.json` に列挙する）と、エディタで補完とチェックが効きます。素の JavaScript ファイルでも恩恵があります。

## 14. 現在の制限

SDK が今のところ意図的に行っていないことです。前もって計画に織り込めるように挙げておきます。

- アプリごとにウインドウは 1 つ。ただしユーザが同じアプリの複数起動を許可した場合を除く（§8 の *インスタンス*）。インスペクタや環境設定のウインドウはない。
- アプリはウインドウが存在する間だけ動く。バックグラウンド実行はないので、バックグラウンド同期はできない。リマインダーはスケジュールされた通知（`macos.notifications.schedule`、§7）で行い、アプリが動いていなくてもシステムが表示する。
- `html` ノードは静的。操作できる独自の領域には、`canvas`（描画とポインタイベント）か Web ランタイムが必要。
- ドラッグできる仕切りのある分割ビューはない。`stack`、`canvas` のポインタイベント、`macos.ui.showMenu()` を組み合わせて作る。
- `macos.storage` はクエリのないキー/値ストア（値ごとに 4 MB、アプリごとに 32 MB）。大量のデータは `macos.files` に置く。
- ブラウザが予約しているショートカット（`⌘T`、`⌘W`、`⌘N` など）は決して割り当てられない。
- SDK は活発に開発中で、ビルド間でパッケージの互換性は保たれない。

## 15. 起動時に開く

設定 → アプリケーション には、インストール済みの各アプリケーションに **新しいタブで自動的に開く** スイッチが表示されます。デフォルトはオフで、ユーザの設定でしかありません。アプリケーションパッケージはこれを要求できず、`macos` API はこれを変更できず、設定ファイルを読み込むとオフに戻ります。

## 16. 制限オーバーレイのパッケージ

「Web 時間管理」のオーバーレイは、実行可能なものではなく、引き続き宣言的なものです。

```json
{
  "id": "my-limit-overlay",
  "name": "My Overlay",
  "version": "1.0.0",
  "kind": "limit-overlay",
  "actions": ["delay5", "dismiss"],
  "overlay": {
    "html": "<main>...<button data-macos-action=\"delay5\">Five more minutes</button></main>",
    "css": "..."
  }
}
```

`delay5` アクションと、それに対応する `[data-macos-action="delay5"]` コントロールが必須です。制限オーバーレイは、実行可能なアプリのランタイム API を受け取りません。

### デベロッパツール：タスクマネージャとパフォーマンスモニタ

開発者モード ▸ デベロッパツール がオンのとき、アプリケーションがデスクトップにかけている負荷を 2 つのパネルが示します。

- **タスクマネージャ** は、実行中のすべてのアプリケーションウインドウを一覧にします — 状態、1 秒あたりの API 呼び出し数、それに応えるためにシステムが使うメインスレッド時間、送られたイベント数、ネイティブインターフェイスの大きさ — 「表示」「再読み込み」「終了」付きで、その下にシステム自身のウインドウが並びます。
- **パフォーマンスモニタ** は直近 1 分間をグラフにします：フレームレート、最も遅いフレーム、長いタスク、JS メモリ、DOM のサイズ、アプリケーションとシステムの間の通信量、そして占める割合の順に並べたアプリケーション。

アプリケーションがサンドボックスの中で何をしているかは、ホストからは見えません。そこで重いアプリケーションは、自身の通信量は少ないのにフレームレートが低い、という形で現れます。

## 17. Public Beta 0.6.2 のホストの挙動

- **追加機能を無効化** は、アプリのランタイムをサスペンドし、プラグインのランチャーをデスクトップ、Dock、Launchpad、Spotlight から隠します。保存済みのランチャー構成は削除しません。
- **すりガラスの代わりに透明表示を使用**（設定 → アクセシビリティ）は、同じ意味の半透明ウインドウマテリアルを保ちつつ、ホストの背景サンプリングを無効にします。そこにある表示オプション — 視差効果を減らす、透明度を下げる、コントラストを上げる — は、開発者モードなしで適用されます。アプリケーションは `macos.context` / `macos.system.getInfo()` でそれらを見られます。
- **厳格なセキュリティを無効化** は、ユーザが個々のアプリケーションを緩和できるようにします。ホストの DOM や `chrome.*` へのアクセスを与えるものではありません。
- **ウインドウ。** デスクトップの左端または右端にドラッグしたウインドウはその半分を占め、上端にドラッグするとデスクトップ全体に広がります（設定 → デスクトップとウインドウ）。そこから引き離すと元のサイズに戻ります。半分のサイズはウインドウの `minWidth` / `maxWidth` を守り、マニフェストが両方向のサイズ変更を許していないウインドウは横に並べられません。アプリケーションには通常の `resize` イベントで伝えられます。
- **右から左。** アラビア語はシステム言語の 1 つです。これを使うとき、または 開発者 ▸ **右から左へのレイアウトを強制**（テキストはそのまま）を使うとき、デスクトップは鏡像になります：メニューバー、Dock、ウインドウの内容と信号機ボタン、左側の通知センター。ウインドウ自体は引き続き画面座標で配置されます。
- **ウインドウの記憶。** アプリケーションのウインドウは、ユーザが最後に置いた位置とサイズで再び開きます（拡大またはタイル表示されたウインドウは、戻る先のフレーム）。その後デスクトップが小さくなっていれば、画面内に収められます。`window.width` / `height` は初回起動時のサイズです。
- **字幕** はユーザが配置します：下、上、または映像上のドラッグした場所（設定 → アクセシビリティ → 字幕）。
- **デベロッパツール** には専用のアイコンがあります：ツールがオンの間は Launchpad に、そのウインドウが開いている間は Dock に表示されます。
- **Mission Control**（⌃↑、F3、または「ウインドウ」メニュー）は、開いているすべてのウインドウを並べて表示します。ウインドウは縮小されているだけで、生きたままです。アプリケーションはこれについてイベントを受け取りません。
- アプリケーションパッケージは、アプリが実際に開かれたときにだけ読み込まれます。
- Launchpad のネイティブな横方向のページ送りは、ブラウザのスクロール物理と CSS scroll snap によるものです。アプリは Launchpad のページ送りの挙動を横取りしたり合成したりできません。
