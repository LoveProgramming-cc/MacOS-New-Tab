# メニュー、インスタンス、セキュリティレベル、デベロッパツール

アプリケーション SDK ドキュメントの一部です — [README](../../README.ja.md) から読み始めてください。

## 8. アプリケーション固有のメニューバー

アプリはメニューバーのメニューを宣言できます。

```json
"menus": [
  {
    "title": "File",
    "titleKey": "menuFile",
    "items": [
      { "label": "New", "labelKey": "menuNew", "command": "new", "shortcut": "⌥⌘N" },
      { "separator": true },
      { "label": "Delete", "command": "delete", "danger": true }
    ]
  }
]
```

### アプリケーションメニュー

すべてのアプリは、メニューバーに太字で表示される自分の名前の下に、標準のアプリケーションメニューを自動的に得ます：**について**（名前、バージョン、説明、権限）、**設定…**、**非表示**、**ほかを非表示**、**すべてを表示**、**終了**。ウインドウの扱いはホストが実装します。アプリはそのために何もしません。

**設定…** — 独自の設定インターフェイスを持つアプリは、マニフェストで `"settings": true` を宣言し、`settings` イベントを受け取ったときにそのインターフェイスを表示します。

```js
macos.on('settings', () => { settingsOpen = true; render(); });
```

`"settings": true` がない場合、「設定…」は システム設定 ▸ アプリケーション を、そのアプリの行で開きます（起動時に開く、書き出し、アンインストール）。ホストはアプリごとの環境設定を生成しません。言語の選択、アクセントカラー、その他アプリが設定可能にしたいものは、アプリが自分で作ります。

独自の追加項目は `appMenu` に入れ、通常のメニューコマンドとして届きます。

```json
"appMenu": [ { "label": "Check for Updates…", "labelKey": "menuUpdates", "command": "updates" } ]
```

Dock にアイコンがないまま実行中のアプリは、Dock のアプリケーションの末尾に現れます。ユーザはそのアイコンを他のアイコンの間にドラッグするか、そのコンテキストメニューの **Dock に追加** で残しておけます。

非表示または最小化されたアプリは動き続け（オーディオは続きます）、インジケータ付きで Dock に残ります。Dock アイコンをクリックすると戻ってきます。アプリには `visibilitychange` で伝えられます。

### インスタンス

アプリケーションのウインドウは 1 つです。もう一度開くと、そのウインドウが表示されます。

ユーザは 開発者 ▸ **アプリケーションの複数起動** で、それ以上を許可できます。全体のスイッチ、アプリケーションごとの上限、そして各アプリケーションについて、複数回開けるかどうか、追加のウインドウがストレージを共有するかどうかです。これはユーザの設定であり、パッケージが要求することはできません。許可されると、アプリケーションメニューと Dock アイコンのコンテキストメニューに **新規ウインドウ** が現れます。

各インスタンスは別々のランタイムです。それぞれのサンドボックス、状態、メディアプレーヤーを持ちます。`macos.storage` と `macos.files` は次のどちらかです。

- **共有**（デフォルト）— すべてのインスタンスが同じプールを読み書きします。インスタンスは互いの書き込みを知らされません。この形で動かすつもりのアプリは、自分だけが書き込んでいると仮定せず、必要なものを読み直してください。
- **個別** — インスタンス 1 はアプリのプールを使います。インスタンス *n* はその番号で保持される自分のプールを持つので、2 つ目のウインドウは次に開いたときに自分のデータを再び見つけます。

`macos.context.instance` と `macos.context.sharedStorage` が、どちらの場合なのかを示します。アプリケーションをアンインストールすると、すべてのプールが削除されます。

1 つのアプリケーションのウインドウ同士は、何が変わったかを伝え合えます。

```js
await macos.instances.broadcast({ type: 'note-updated', id });           // 他のすべてのウインドウへ。届いた数で resolve する
macos.on('instancemessage', ({ from, message }) => {});                   // from：送信側のインスタンス番号
const windows = await macos.instances.list();                             // [{ instance, self, front, title, sharedStorage }]
```

システム設定 ▸ **ストレージ** は、各アプリケーションが占めている量 — アプリケーション自体とそのデータとファイル — を示し、ユーザがアプリケーションのデータをまるごと消去できるようにします（先にそのウインドウが閉じられ、次の起動は空の状態から始まります）。それより細かいこと — 使われていないファイルの削除、ある種類の内容の消去 — は、「ミュージック」がそうしているように、アプリケーションが自身の設定で提供するものです。そこにある **データを書き出す…** は、1 つのアプリケーションが保存したすべて — 各プールのキー/値ストレージと保存されたすべてのファイル、それに `data.json` のカタログ — を 1 つのアーカイブとして保存し、**データを読み込む…** はそのようなアーカイブでアプリケーションのデータを置き換えます（同じアプリケーションのものでなければなりません）。どちらもシステムの機能で、アプリケーション側には何も必要ありません。

**どの書き出しがどこに属するか。** アプリケーションが持つ *すべて* のバックアップ、復元、移動はシステムの仕事です（上の 2 つのボタン）。独自の「すべて書き出す」を作らないでください。アプリケーション自身の書き出しは、*ユーザが 1 つのまとまりとして考え、他の人や他のプログラムに渡すもの* — 曲を含む 1 つのプレイリスト、1 冊の本、1 つの書類 — のためのもので、アプリケーションの外でも意味のあるフォーマットにします。「ミュージック」は単一のプレイリスト（`macos.archive`）と単一の曲（`macos.files.export`）を書き出し・読み込みでき、ライブラリ全体については、その設定が システム設定 ▸ ストレージ を案内します。

### アプリのメニュー

そのアプリのウインドウがアクティブになると、デスクトップのメニューバーはそのアプリのメニューに切り替わり、ウインドウがアクティブである間、各項目の `shortcut` が割り当てられます。ショートカットは `⇧⌘S`、`Cmd+Shift+S`、`Ctrl+S` のように書きます。`⌘` は Ctrl にも一致します。ショートカットには ⌘ / Ctrl / ⌥ のうち少なくとも 1 つが必要で、ブラウザが自分用に予約している組み合わせ（`⌘T`、`⌘W`、`⌘N` など）は決して割り当てられません。コマンドはアプリのサンドボックスに届けられます。

```js
macos.on('menucommand', ({ command }) => {
  if (command === 'new') {
    // ...
  }
});
```

アプリは意味的なコマンドを宣言するのであって、メニューバーの DOM を操作するのではありません。

## 9. 厳格なセキュリティ

厳格なセキュリティがデフォルトで、アプリケーションごとに決まります。

開発者モードには **厳格なセキュリティを無効化** があります。このスイッチはデフォルトでオフで、オンにしてもそれだけでは何も緩和されません。各アプリケーションについて **セキュリティレベル** を選べるようになるだけです（設定 → 開発者 → アプリケーションのセキュリティ）— *厳格* または *緩和*。ユーザが「緩和」に設定しなかったアプリケーションは厳格のままです。パッケージがレベルを要求することはできず、読み込まれた構成がレベルを持ち込むこともできません。

厳格なセキュリティの下に収まらないパッケージ（大きすぎる、ファイルが多すぎる）は拒否されます。スイッチがオンの間は、その 1 つのアプリケーションを緩和でインストールするかどうかを、代わりにユーザに尋ねます。

厳格モードでは、ホストは明示的な制限を適用します。

- 現行のアプリケーションパッケージ形式は `macos-app-package-v3` でなければならない。
- パッケージの JSON は約 2.5 MB、仮想ファイル 160 個までに制限される。
- エントリの HTML/CSS/JavaScript のサイズには上限がある。
- Web App の HTML は、実行可能な `<script>` タグやインラインの `on...` ハンドラを含められない。コードは `entry.script` から来る。
- 埋め込みの `iframe`、`object`、`embed`、外部の `link`、`meta` の内容は取り除かれる。
- パッケージの HTML/CSS 内の外部 HTTP/HTTPS リソース参照はブロックされる。
- CSS の `@import` は取り除かれる。
- パッケージ作者による `backdrop-filter` と `filter: blur(...)` は取り除かれる。代わりにホスト/ネイティブのマテリアルを使う。
- 厳格なサンドボックスページ（`plugin/app-runtime-strict.html`）は Content-Security-Policy を持ち、いかなる種類のネットワーク接続も入れ子のフレームも許さず、画像、フォント、メディアは、ホストがパッケージのアセット用に渡す `data:` / `blob:` URL からのみ読み込む。これが実際の境界であり、スクリプトからは迂回できない。
- 早い段階で読みやすいエラーにするため、直接の `fetch`、XHR、WebSocket、EventSource、SharedWorker、`window.open` も、例外を投げる関数に置き換えられる。権限の境界は、宣言されたホスト API が提供する。
- `macos.fetch` はこのマシンやプライベートネットワークのアドレスに到達できない。
- ネットワークリクエストの同時実行数は制限される。
- ホスト API の呼び出しは、アプリごとに毎秒 240 回に制限される（厳格なセキュリティが無効のときは 1 200 回）。`ui.batch` / まとめられた `patch` は 1 回と数える。
- worker は `blob:` スクリプトからのみ作成でき、同じネットワーク禁止ポリシーを引き継ぐ。
- `setInterval` は少なくとも 16 ms の 1 フレームに切り上げられ、有効なインターバルの数には上限がある。
- ホストが管理ウインドウをドラッグしている間、またはアプリが表示されていない間、インターバルのコールバックは一時停止する。
- サンドボックスは、新しいタブのページの DOM、他のアプリのストレージ、`chrome.*` の拡張機能の特権にアクセスできない。
- アプリケーションのクラッシュは、デスクトップのシェルから隔離される。

**緩和** に設定されたアプリケーションでは、パッケージ/リソース/コードの制限が緩められ、より重い CSS/外部リソースが許されることがあります。それでも Manifest V3 のサンドボックス内で実行され、ホスト API には引き続き宣言された権限が必要です。`macos.context.strictSecurity` が、2 つのうちどちらの下で動いているかをアプリケーションに伝えます。

アプリケーションのレベルを変更すると、そのウインドウが閉じます。開き直すと、新しいポリシーの下で起動します。

## 制限なしのアプリケーション

厳格なセキュリティをオフにすると（開発者 ▸ **厳格なセキュリティを無効化**）、さらにスイッチが 1 つ現れます：**制限なしのアプリケーション**。ユーザは、結果を明記した 2 回の確認を経てこれをオンにします。これは 3 つ目のセキュリティレベル *制限なし* を追加し、ユーザがその後アプリケーションに 1 つずつ与えます。すべてのアプリケーションに適用されることは決してなく、パッケージが要求することはできず、読み込まれた構成が持ち込むこともできません。

選ばれたアプリケーションについて、ホストは、権限の宣言（すべての API が使える）、ストレージとファイルのクォータ、ファイル・レスポンス・パッケージのサイズ制限、レート制限、ノード数の制限、ローカルおよびプライベートネットワークのアドレスのブロックを、もはや強制しません。アプリケーションは引き続きサンドボックス化されたフレームの中で動きます。

## デベロッパツール

開発者モード ▸ **デベロッパツールを有効にする** で、デベロッパツールのウインドウが加わります（アップルメニュー、またはスイッチの横のボタン）。オフの間は何も記録されません。

| パネル | 用途 |
| --- | --- |
| *（ランチャー）* | デベロッパツールがオンの間、**デベロッパツール** アプリケーションが Launchpad に現れます（Finder ▸ アプリケーション と Spotlight にも）。他のアプリと同じように Dock に残しておけます。 |
| アプリケーション | **フォルダから読み込む…** は、ソースディレクトリからアプリを直接インストールし（`plugin/tools/pack.py` が書き出すのと同じパッケージを、ページ内で組み立てます）、ファイルが変わるたびに再読み込みします — 作業中にパッケージ化や読み込みは要りません。フォルダへのアクセスはページが開いている間だけ続きます。**フォルダをパッケージ化…** と **パッケージを書き出す** は、インストール可能な `<id>.macos-app.json` を書き出します — フォルダから（インストール時と同じ方法でチェックされます）、またはインストール済みのパッケージから。アプリケーションごとの **シミュレートする条件**：表示言語、ライト/ダークの外観、ウインドウサイズ（マニフェストの最小値とデフォルト、およびよくあるサイズ）、表示スケール（75–200 %。アプリはそれに応じて少ない、または多いポイント数でレイアウトされ、`devicePixelRatio` も追従します）、拒否された権限、オフライン（`macos.fetch` が失敗）、ストレージ満杯（`storage.set` とファイルの保存が失敗）。**権限の使用状況**：各権限と、それが使われた回数。使われていないものと拒否されたものは目立つように表示されます。 |
| コンソール | `macos.log` の出力、捕捉されなかったエラーとクラッシュ、すべての API 呼び出しとその引数・結果・所要時間、そして（オプションで）ホストが送るイベントとシステムイベント。**パフォーマンス予算**：1 フレーム（16.7 ms）より長くかかったインターフェイス更新（`ui.*`）に印が付き、1 秒以内に 90 回を超える API 呼び出しをしたアプリケーションにも印が付きます。 |
| インターフェイス | ネイティブアプリの生きたノードツリー。id、サイズ、行数がノード上限と照らして表示されます。ノードを指すとウインドウ内で強調表示され、クリックするとそのプロパティが表示されます。**レイアウト境界を表示** はすべてのノードに輪郭を付けます。 |
| ストレージ | アプリケーションのキー/値エントリ（JSON として編集可能）と保存されたファイル。ストレージプールごと。 |
| 記録と再生 | ホストがアプリケーションに送る入力イベント — コントロールのイベント、キー、メニューコマンド、Spotlight の結果、ステータス項目と通知のクリック — を記録し、元の速度、×4、または可能な限り速く再生します。オプションで、アプリケーションを再読み込みしてから再生できます。コードを変えて再生すれば、アプリは作業していた状態に戻ります。記録は JSON として書き出し・読み込みできます。 |
| システム | フレームレート、長いタスク、DOM のサイズ。すべてのウインドウとその状態、順序、サイズ変更のルール。各デスクトップ面が再描画された回数とスキップされた回数。内部イベントと構成の保存。 |
| 構成 | 正規化された構成をツリーとして表示。オプションで、デフォルトと異なる箇所だけ。診断情報の書き出し。 |

開発者ページの **スローモーションアニメーション**（÷2、÷4、÷10）は、すべてのアニメーション — ウインドウの飛行、ネイティブのトランジション、CSS トランジション — を、動作を変えずに遅くします。
