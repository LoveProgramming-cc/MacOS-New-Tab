# macOS New Tab プラグイン / アプリケーション SDK — Public Beta 0.6.2

Public Beta 0.6.2 には 2 種類の拡張パッケージがあります。

- `kind: "app"` — 管理された macOS 風のウインドウで開く、実行可能なアプリケーション。
- `kind: "limit-overlay"` — 「Web 時間管理」の宣言的な制限オーバーレイ。

アプリケーションは **1 つの JSON ファイル** からインストールします。**設定 → アプリケーション** で読み込むか、そのファイルをデスクトップにドロップします。この JSON は仮想的なディレクトリツリーを表すので、アプリケーションは HTML、CSS、JavaScript、JSON、SVG/PNG/WebP 画像、フォントなどのリソースを含めることができ、読み込み時に実際のフォルダは必要ありません。

## Public Beta 0 の互換性ポリシー

アプリケーション SDK はまだ Public Beta 0 の段階にあり、アーキテクチャが安定するまでは、互換性を壊す変更を意図的に許しています。

**Public Beta 0.6.2 は、古いインライン形式の `app.html / app.css / app.script` パッケージレイアウトを受け付けません。** アプリケーションパッケージは、以下で説明する現行の `macos-app-package-v3` ディレクトリ形式を使う必要があります。API がまだ変化している間、ランタイムに互換性のための分岐を抱え込まないためです。

これは **macOS New Tab 全体の設定 JSON** とは別の話です。古い書き出し済みの設定 JSON は、引き続きホストの構成ローダーが対応します。サポートされている構成フィールドが欠けていたり不正だったりする場合は、現行の `default.json` のスキーマに基づいて修復されます。

## 1. アプリケーションのアーキテクチャ

Public Beta 0.6.2 は 2 つのランタイムをサポートします。

### Native App — 推奨

```json
"runtime": "native"
```

Native App は、目に見える UI をホストのデスクトップ DOM の中に持ちます。パッケージは意味的な UI 記述（`entry.ui`）と、サンドボックス内で動く JavaScript のロジックファイル（`entry.script`）を提供します。実際のコントロール、マテリアル、タイポグラフィ、フォーカスの挙動、アクセシビリティの面はホストが作ります。

アプリをシステムのコントロールで表現できるなら、こちらのランタイムを選んでください。次のものが得られます。

- システムが受け持つ macOS の見た目。
- ライト/ダーク、透明度、コントラスト、言語への自動対応。
- 目に見える iframe のドキュメントツリーがない。
- DOM とコンポジタのオーバーヘッドが小さい。
- サードパーティアプリ間で一貫したボタン、入力欄、スイッチ、メニュー、フォーカスの挙動。
- 将来の SDK の見た目の改善を、各アプリが新しい CSS を同梱せずに受けられる。

サンドボックスに残るのはロジックのランタイムだけです。

### Web App — 自由形式

```json
"runtime": "web"
```

Web App は隔離されたサンドボックス iframe を受け取り、独自の HTML/CSS レイアウトを使えます。外側のウインドウ、タイトルバー、信号機ボタン、影、そして負荷の大きい壁紙の背景マテリアルは、引き続きホストのものです。

Web App モードは、Native App のコントロール群ではまだ表現できない自由形式の HTML/CSS が UI に本当に必要な場合にだけ使ってください。
