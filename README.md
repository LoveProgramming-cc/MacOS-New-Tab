# MacOS New Tab

把 Chrome 的新标签页换成一个 macOS 风格的桌面：程序坞、启动台、菜单栏、聚焦搜索、小组件、访达、系统设置，以及一套可以安装第三方应用程序的沙盒应用系统。

当前版本：**Public Beta 0.6.2**。之后计划是 Release Candidate 0.7.x 和正式版 1.x。测试版期间，应用程序 SDK 不保证版本之间兼容。

> 本项目是 macOS 界面的非官方网页实现，仅供学习与研究。它与 Apple Inc. 没有任何关联；Apple、macOS 及相关商标归 Apple Inc. 所有。

## 功能

- **桌面**：壁纸（浅色/深色、每日 Bing 壁纸）、桌面图标、程序坞、启动台、菜单栏、聚焦搜索、通知中心、调度中心。
- **窗口**：拖动、缩放、贴边平铺、最小化到程序坞，磨砂玻璃材质。
- **系统应用**：访达、系统设置、关于本机、网页时间管理。
- **小组件**：桌面和小组件中心，应用程序也可以提供自己的小组件。
- **应用程序系统**：应用以一个 JSON 文件安装，在沙盒中运行，按权限访问存储、文件、音频、网络、通知等接口。自带的示例有音乐、图书、计算器、桌面宠物“星野”、桌面天气“窗外”和“纸飞机”。
- **开发者工具**：从文件夹载入并热重载应用、控制台、界面检查器、存储浏览、录制与回放、任务管理器、性能监视器。
- **语言**：简体中文、English、日本語、한국어、العربية（含从右到左布局）。

## 安装

目前只能以“未打包的扩展程序”方式安装：

1. 下载或克隆本仓库。
2. 在 Chrome 中打开 `chrome://extensions`，打开右上角的“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择本仓库的根目录。
4. 打开一个新标签页。

示例应用程序在 `plugin/examples/` 下，后缀为 `.macos-app.json`。在 设置 → 应用程序 中导入，或者直接把文件拖到桌面上。
